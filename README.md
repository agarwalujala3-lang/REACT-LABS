## ⚙️ Local Development Setup

Want to run any of the apps or drills locally? Follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate to the active workspace:**
   ```bash
   cd REACT-LABS/my-react-app
   ```

3. **Install dependencies & launch:**
   ```bash
   npm install && npm start
   ```
